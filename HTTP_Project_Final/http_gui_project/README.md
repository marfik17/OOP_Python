# HTTP-клиент и сервер с графическим интерфейсом на Python

Учебный проект на стандартной библиотеке Python: `tkinter`, `socket`, `ssl`, `threading`, `queue`, `logging`, `unittest`.

## Запуск (Windows)
1. Установите Python 3.10 или новее. При установке отметьте **Add Python to PATH**.
2. Распакуйте архив в отдельную папку.
3. Откройте терминал в папке `http_gui_project` (внутри должны быть папки `src` и `tests`).
4. Запустите приложение:

```powershell
python -m src.main
```

## Проверка тестов
Откройте второй терминал в той же папке и выполните:

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют URL-парсер, HTTP-сериализацию и разбор ответов, chunked-тело, маршрутизацию и обмен клиента с сервером через реальные локальные TCP-сокеты.

## Быстрая ручная проверка
1. На вкладке **HTTP-сервер** оставьте порт `8080` и нажмите **Запустить**.
2. На вкладке **HTTP-клиент** отправьте `GET http://127.0.0.1:8080/`.
3. Выберите `POST`, укажите URL `http://127.0.0.1:8080/echo`, в теле напишите `hello` и нажмите **Отправить**.
4. Проверьте `GET http://127.0.0.1:8080/time`, `GET http://127.0.0.1:8080/headers`, `GET http://127.0.0.1:8080/status/418` и несуществующий маршрут, например `/abc`.
5. Сделайте собственные скриншоты работающего приложения и успешного вывода тестов для отчёта.

## Реализованные маршруты
- `GET /` — HTML-страница;
- `POST /echo` — возвращает тело запроса;
- `GET /time` — текущее время в JSON;
- `GET /headers` — полученные заголовки в JSON;
- `GET /status/{code}` — демонстрационный ответ с указанным кодом;
- неизвестный маршрут — `404 Not Found`.

Клиент поддерживает HTTP и HTTPS (TLS), GET/POST, пользовательские заголовки, тайм-аут, Content-Length и разбор chunked-ответов. Сервер принимает обычные запросы с Content-Length и chunked-тело. TLS-сервер не реализован.
